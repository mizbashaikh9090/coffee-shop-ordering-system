Coffee Shop Ordering System

A terminal-based coffee shop ordering system developed using Python. It allows users to select items from a menu, place orders, and view the final bill.

Features

- Displays a coffee shop menu.
- Allows users to select items to order.
- Accepts user input for placing orders.
- Calculates the total bill.
- Displays the final bill in the terminal.

Technologies Used

- Python 3

How to Run

1. Clone this repository:
   
   git clone https://github.com/mizbashaikh9090/coffee-shop-ordering-system.git

2. Navigate to the project folder:
   
   cd coffee-shop-ordering-system

3. Run the program:
   
   python main.py
